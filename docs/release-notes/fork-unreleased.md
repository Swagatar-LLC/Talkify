You can now choose Whisper large-v3-turbo as your speech recognizer in Settings → Recognizer. It spells names and terms from your Vocabulary more reliably than Apple Speech, and finishes about 0.8 s later after you release the key. It is a 650 MB download that happens only when you tap Download, runs entirely on your Mac, and never sends anything you say. If it cannot load, that session uses Apple Speech and Settings tells you why. Requires macOS 26.7 or later.

Update checks now require a signed update feed.

Settings → Dictation now lets you retain a preferred microphone by its persistent device identity and shows the effective input and its live level while the section is open. Both Apple Speech and Catalog Models share this selection. If the preferred device is missing, Talkify retains the preference and uses System until it returns; System can select a Bluetooth microphone. Closing Settings releases idle monitoring, and Direct Dictation takes exclusive capture ownership.

The combined fork includes guarded native tap installation on macOS 27 and nonblocking Settings capture requests. Physical Bluetooth recovery and macOS 26 exception containment still need attended verification. Whisper rolling partials are not included: Catalog Model recognition still finishes at session end.

For a local installation, build with `release/swagatar-release.sh build` with `SWAGATAR_SUPUBLIC_KEY` unset. Keep the normal `co.swagatar.Talkify` identity to reuse preferences, Vocabulary and installed Catalog Models; the isolated Input Soak bundle is not a replacement. Before copying the signed Release app to `/Applications/Talkify.app`, quit every Talkify candidate and preserve the current app in a durable backup. Verify the copied signature and launch path; restore that backup if launch fails. Do not reset preferences or macOS permissions. Approve any permission requests interactively and select the intended microphone in Settings before attended dictation. A local install is not a public release or completed hardware soak.
